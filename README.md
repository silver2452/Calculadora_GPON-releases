# Calculadora GPON — descargas

Aquí se publican las versiones de **Calculadora GPON**. La aplicación consulta
este repositorio para avisar de las versiones nuevas y descargarlas.

Descarga la última versión en [Releases](../../releases/latest):

- `CalculadoraGPON-<versión>.apk`: Android.
- `CalculadoraGPON-<versión>-instalador.exe`: instalador de Windows.
- `CalculadoraGPON-<versión>-portatil.zip`: Windows sin instalar.
